# EZ Cast 🎬

EZ Cast 是一個專為影視劇組打造的「演員與服裝管理」及「拍攝場次排程」桌面應用程式。結合現代化的玻璃擬物（Glassmorphism）美學，提供流暢且直覺的使用者體驗，協助劇組高效地統籌龐大繁雜的拍攝資訊。

## ✨ 核心功能特色

### 👗 1. 完善的演員與服裝資料庫
- **演員獨立建檔**：可無限新增演員，並分別記錄「劇中角色名」與「演員本名」。
- **角色職稱自訂**：可自由定義演員為「主角」、「客串」等職稱，協助快速辨識角色比重。
- **服裝多樣化管理**：支援為同一位演員新增多套服裝，且系統內建「防呆檢查機制」，若為同一位演員輸入重複的服裝名稱，將會主動警告並攔截。
- **一鍵上傳定妝照**：支援匯入每套服裝的專屬定妝照，滑鼠懸停即可預覽，視覺化管理一目瞭然。

### 📅 2. 高度彈性的拍攝排程系統
- **天數與場次自由新增**：以「拍攝日（DAY）」為單位進行排程，支援隨時增加拍攝日與無上限的場次。
- **直覺的拖曳排序 (Drag & Drop)**：
  - 場次順序：可直接按住場次進行上下拖曳排序。
  - 日期順序：整天的拍攝計畫也可以隨時上下拖曳對調，完美因應劇組瞬息萬變的行程。
- **精準指派演員服裝**：在特定的場次中，可從下拉式選單直接點選「演員 + 特定服裝」將其加入該場戲，表格標籤（Pill）會清楚標示出場演員，方便統籌梳化進度。
- **詳細的拍攝資訊紀錄**：每個場次皆可記錄包含「時間」、「場次編號」、「劇本頁數」、「拍攝內容」以及「備註（例如：交通、道具）」，並維持工整的置中/靠左舒適排版。

### 💾 3. 專屬專案檔與本機存檔機制
- **自訂專案格式 (`.cast`)**：所有的劇組資料都能儲存與匯出為專屬的 `.cast` 專案檔。
- **跨裝置共享與備份**：檔案極度輕量，您可以將其傳送給其他劇組人員，對方只要使用 EZ Cast 匯入即可繼續編輯與檢視。
- **安全不遺失**：應用程式支援本機儲存與直接覆蓋寫入，保障資料安全性。

## 📥 下載與安裝

您可以直接從本專案的 GitHub Releases 頁面下載最新版本的 EZ Cast 應用程式，免去自行編譯的繁瑣步驟：

1. 前往右側區塊或點擊連結進入 [Releases 頁面](https://github.com/sutimlong/ez-cast-app/releases)。
2. 在最新的發布版本（通常標示為 **Latest**）下方，展開 **Assets** 區塊。
3. 根據您的作業系統，點擊下載對應的安裝檔：
   - **Windows 用戶**：下載結尾為 `.exe` 的安裝程式（例如 `EZ Cast Setup x.x.x.exe`）。
   - **macOS 用戶**：下載結尾為 `.dmg` 的映像檔（例如 `EZ Cast-x.x.x.dmg`）或 `.zip` 壓縮檔。
4. 下載完成後，雙擊開啟檔案並按照系統提示完成安裝，即可開始使用！

## 🚀 技術架構
本專案為跨平台桌面應用程式，採用以下技術堆疊：
- **核心框架**: React 19 + TypeScript + Vite
- **桌面應用打包**: Electron & Electron-builder
- **UI 互動與拖曳**: dnd-kit (支援流暢的排序與拖曳)
- **視覺特效**: canvas-confetti
